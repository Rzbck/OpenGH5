# Security policy

**Project status:** early research; no official release or supported firmware patch.

## Responsible disclosure

Please do **not** publish security vulnerabilities, exploit payloads, sensitive protocol captures, private keys or device-specific secrets in a public issue or pull request.

If GitHub's private vulnerability reporting is enabled on this repository, use **Security → Report a vulnerability** to contact the maintainers privately. Otherwise, open a public issue with a generic request for a private contact route **without technical exploit details**.

## Privacy and publishing

- Do not include hostnames, local or public IP addresses, device serials, MAC addresses, Wi-Fi passwords or personal metadata in reports.
- Minimize logs; redact secrets before sharing them.
- Never commit proprietary firmware images or vendor source code beyond its redistribution license.
- Run experimental camera modifications only after separate verification and with full awareness of the risk of permanently disabling a device.

## Supported versions

No software releases are available yet, so there are no supported versions.
